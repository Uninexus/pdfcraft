# Working by keyboard

Help ▸ Keyboard shortcuts lists every command's shortcut. Keys that no command binds are in the same window with
"Show" set to Fixed Keys. This page covers those used to work without a pointer. Ctrl is Command (⌘) on macOS, except
where noted.

## Moving around

| Keys | What it does |
| --- | --- |
| Tab / Shift+Tab | Next or previous control |
| Ctrl+Tab | Next document tab (Ctrl on every platform) |
| F10 | Menu bar |
| Ctrl+K | Search tools and commands |
| Enter / Space | Press the focused button |
| Esc | Close a menu or dialog; leave a comment tool |

## Selecting part of a page's text

Turn on View ▸ Caret browsing (F7). A caret appears at the start of the current page's text. It works with the Select
tool.

| Keys | What it does |
| --- | --- |
| ← → ↑ ↓ | Move by character and line |
| Ctrl+← → | Move by word |
| Home / End | Start or end of the line |
| Shift with any of these | Extend the selection |

Copy and the highlight, underline and strikethrough tools then act on the selection. The keys follow screen directions:
right-to-left text and turned views are not mirrored.

## Placing a sticky note

Choose Add a sticky note, then focus the page view. A marker appears, at the text caret if caret browsing is on and
otherwise in the middle of what shows of the page.

| Keys | What it does |
| --- | --- |
| ← → ↑ ↓ | Move the marker (with Shift, further) |
| Enter | Place the note there and write it |
| Esc | Cancel |

## Not yet by keyboard

Only the sticky note can be placed at a chosen point: text boxes, shapes and drawing need a pointer.
